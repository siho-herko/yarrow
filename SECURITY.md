# Security

`yarrow.hexmath` is pure arithmetic with no network, file-system writes or dependencies. Later components (`yarrow.escalate`, the router) will sit in agent tool paths; for those, and for anything that could let an agent execute in a decision state, please report privately to simon.herko@trigrammatic.com rather than opening a public issue. We will acknowledge within five working days.
